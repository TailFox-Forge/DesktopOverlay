GIF·PNG·JPG·WEBP·BMP를 테두리 없는 투명 창으로 항상 위에 표시합니다. 

기본값이 클릭 통과라 게임이나 작업을 가리지 않고, 트레이 아이콘에서 모든 설정을 바꿀 수 있습니다.

새 릴리스가 있으면 트레이 아이콘 우상단에 빨간점이 표시되고, 트레이 메뉴의 **업데이트 확인**에서 릴리스 페이지를 열 수 있습니다.

## 시스템 요구사항

실행 파일 기준입니다. 파이썬을 직접 설치해서 실행할 때도 요구 수준은 거의 같습니다.

| 구분 | 최소 | 권장 |
|---|---|---|
| OS | Windows 10 64-bit | Windows 11 64-bit 또는 Windows 10 최신 업데이트 |
| CPU | 2코어 x64 CPU | 4코어 이상 x64 CPU |
| 메모리 | 시스템 RAM 4GB, 여유 메모리 500MB 이상 | 시스템 RAM 8GB 이상, 여유 메모리 2GB 이상 |
| GPU | WDDM 지원 내장 그래픽 | 최신 내장 그래픽 또는 외장 GPU |
| 저장공간 | 200MB 이상 | 500MB 이상 |
| 네트워크 | 업데이트 확인 시 인터넷 연결 | 업데이트 확인과 릴리스 다운로드용 인터넷 연결 |

예상 메모리 사용량은 정적 이미지 기준 약 150~300MB입니다.

큰 GIF는 프레임을 처리하므로 해상도와 프레임 수에 따라 1GB 이상까지 늘 수 있습니다.

대형 GIF는 응답성을 유지하기 위해 자동으로 제한합니다.

- 프레임당 최대 픽셀 수: **4,000,000px**
- GIF당 최대 보관 프레임 수: **180프레임**
- GIF당 전체 보관 픽셀 예산: **100,000,000px**
- 제한을 넘는 GIF는 전체 재생 시간을 유지하도록 프레임 간 지연시간을 합산하고, 일부 프레임만 균등 샘플링합니다.
- 너무 큰 프레임은 비율을 유지해 축소하며, 적용 시 트레이 알림으로 알려줍니다.

## 다른 도구와 뭐가 다른가

배경 제거를 **색이 아니라 피사체의 외곽선을 경계로** 처리합니다.

흔한 컬러키(크로마키) 방식은 "흰색인 픽셀을 지운다"는 식이라, 캐릭터에 흰 머리나 흰 옷이 있으면 그 부분까지 같이 뚫립니다. 

이 프로그램은 이미지 가장자리에서 시작해 **외곽선에 막힐 때까지만** 배경을 지우기 때문에, 피사체 안쪽의 흰색은 그대로 남습니다.

배경색은 네 모서리에서 자동으로 추출하므로 흰색이든 초록이든 검정이든 따로 지정할 필요가 없습니다.

이미 배경이 투명한 PNG·GIF는 자동으로 감지해서 손대지 않습니다.

## 실행 방법

### 파이썬 없이 (권장)

[릴리스 페이지](https://github.com/TailFox-Forge/DesktopOverlay/releases/latest)에서 `Desktop_Overlay_Start.exe` 를 내려받아 더블클릭하면 됩니다.

설정은 기본적으로 exe 가 놓인 폴더에 `config.json` 으로 저장됩니다.

그 폴더에 쓸 수 없으면 `%LOCALAPPDATA%\DesktopOverlay\config.json` 으로 자동 전환하고 트레이 알림으로 알려줍니다.

### 소스에서

Python 3.8 이상이 필요합니다.

릴리스 페이지의 **Source code (zip)** 을 받거나 저장소를 클론하세요.

`Desktop_Overlay_Start.bat` 을 더블클릭하면 파이썬과 라이브러리를 점검한 뒤 실행합니다.

파이썬이 없으면 설치 페이지를 열어 안내하고, 라이브러리가 없으면 자동으로 설치합니다.

직접 실행할 수도 있습니다.

```bash
pip install -r requirements.txt
python desktop_overlay.py
```

이미지를 인자로 넘기거나, `Desktop_Overlay_Start.bat` 위로 이미지 파일을 끌어다 놓아도 됩니다.

```bash
python desktop_overlay.py character.gif
```

바로가기를 만들어 시작 프로그램 폴더에 넣으면 부팅 시 자동 실행됩니다.

### exe 직접 빌드

`build.bat` 을 실행하면 고정된 빌드 도구 버전으로 `dist\Desktop_Overlay_Start.exe` 가 만들어집니다.

```bat
build.bat
```

테스트는 아래처럼 실행합니다.

```bash
pip install -r requirements.txt -r requirements-build.txt
pytest
```

## 처음 실행하면

띄울 이미지가 없으므로 화면에는 아무것도 나타나지 않습니다.

대신 트레이 아이콘에서 알림이 뜹니다.

트레이 아이콘을 클릭해 **이미지 열기** 로 원하는 이미지를 고르세요.

한 번 고른 경로는 저장되어 다음 실행 때 자동으로 불러옵니다.

그 이미지를 옮기거나 지워서 찾을 수 없게 되면, 시작할 때 알림으로 알려주고 다시 선택하도록 안내합니다.

예외는 **숨김 상태**입니다.

이건 저장하지 않기 때문에, 숨긴 채로 종료해도 다음 실행 때는 정상적으로 보입니다.

### 윈도우 시작 시 자동 실행

트레이 메뉴의 **윈도우 시작 시 자동 실행**을 체크하면 Windows 시작프로그램 폴더에 현재 실행 파일을 가리키는 `DesktopOverlay.lnk` 바로가기를 만듭니다.

체크를 해제하면 이 바로가기를 삭제합니다.

프로그램 파일이나 폴더를 옮긴 뒤에는 기존 바로가기가 예전 경로를 가리킬 수 있습니다.
자동 실행이 켜져 있으면 메뉴에 **자동 실행 경로 갱신**이 같이 표시되며, 이 항목을 누르면 현재 실행 위치로 바로가기를 다시 만듭니다.

## 단축키

단축키는 설치 직후 모두 미등록 상태입니다.

트레이 메뉴의 **단축키 설정**을 열면 주 모니터 중앙에 설정창이 뜹니다. 각 항목의 버튼을 누른 뒤 원하는 키를 입력하면 등록됩니다.

- `Backspace` 또는 `Delete`: 해당 항목 단축키 삭제
- **삭제** 버튼: 해당 항목 단축키 삭제
- **전체 초기화**: 등록된 단축키 전체 삭제
- 수식어 없는 단독키처럼 입력을 방해하는 키나 사용할 수 없는 키는 안내 후 등록하지 않습니다.
- 넘버패드 숫자(`Num0`~`Num9`)는 일반 숫자와 분리해 단독 등록할 수 있습니다.
- 서로 다른 기능에 같은 단축키를 넣으면 기존 기능의 단축키를 삭제한다고 안내하고 새 기능에 배정합니다.
- **보이기/숨기기 토글**과 **보이기 / 숨기기 개별 단축키**는 동시에 쓰지 않습니다. 한쪽을 등록하면 반대쪽은 자동 삭제된다고 안내합니다.
- **단축키 전체 비활성화** 단축키를 누르면 모든 전역 단축키가 꺼집니다. 다시 켜려면 트레이 메뉴에서 **단축키 활성화**를 선택해야 합니다.
- 단축키 설정창이 열려 있는 동안은 기존 전역 단축키를 잠시 해제해서, 이미 등록된 키도 다른 항목으로 다시 배정할 수 있습니다.

위치 단축키는 설정창 상단에서 선택한 모니터 하나에만 적용됩니다.

## 위치 바로가기

연결된 모니터마다 9개 지점(좌측 상단 · 상단 중앙 · 우측 상단 · 좌측 중앙 · 정중앙 · 우측 중앙 · 좌측 하단 · 하단 중앙 · 우측 하단)으로 한 번에 보낼 수 있습니다.

```
위치 바로가기
├── 주 모니터 1 (1920x1200)  ← 현재
│   ├── 좌측 상단
│   ├── 상단 중앙
│   └── ...
├── 보조 모니터 2 (1920x1080)
│   └── ...
└── 구석 여백: 0px
```

모니터 목록은 메뉴를 열 때마다 다시 읽으므로, 모니터를 연결하거나 분리하면 자동으로 반영됩니다. 

창이 현재 놓인 모니터에는 `← 현재` 표시가 붙습니다.

작업표시줄을 침범하지 않는 영역을 기준으로 계산하며, **구석 여백**으로 화면 끝에서 얼마나 띄울지 정할 수 있습니다.

### 구석 고정

위치 바로가기로 옮기면 그 구석을 기억합니다.

이후 **이미지를 바꾸거나 크기를 조절해도 자동으로 같은 구석에 다시 붙습니다.**

우측 하단에 붙여 둔 캐릭터를 두 배로 키워도 우측 하단에 그대로 있다는 뜻입니다.

고정된 지점에는 메뉴에 `← 고정됨` 표시가 붙습니다.

창을 마우스로 직접 끌어다 놓으면 고정이 해제되고 **커스텀 위치**가 됩니다.

커스텀 위치에서는 이미지나 크기가 바뀔 때 **중심 좌표를 유지**합니다.

크기를 조절해도 캐릭터가 제자리에서 커지고 작아진다는 뜻입니다.

위치는 그대로 두고 고정만 풀고 싶으면 위치 바로가기 메뉴의 **구석 고정 해제** 를 쓰세요.

위치·크기·설정은 실행 파일 옆 `config.json`에 자동 저장되어 다음 실행 때 복원됩니다. 실행 파일 폴더에 저장할 수 없으면 사용자 설정 폴더로 자동 전환됩니다.

## 방송 송출

용도에 따라 두 가지로 나뉩니다.

| 방식 | 필요한 설정 | 방송 툴에서 |
|---|---|---|
| 디스플레이 캡처 | 없음 | 추가 작업 없음 |
| 윈도우 캡처 | **윈도우 캡처 목록에 표시** 켜기 + **방송 캡처용 배경**을 단색으로 | 소스에 **색상 키** 필터 추가 |

윈도우 캡처를 쓰려면 두 가지를 모두 켜야 합니다.

**윈도우 캡처 목록에 표시** 

평소 이 프로그램의 창은 작업표시줄을 어지럽히지 않도록 도구 창(`WS_EX_TOOLWINDOW`)으로 만들어집니다. 

그런데 OBS·PRISM은 캡처 대상 목록에서 도구 창을 의도적으로 걸러내기 때문에, 이 옵션을 켜야 목록에 나타납니다. 

대신 작업표시줄에도 항목이 하나 생깁니다.

**방송 캡처용 배경** 

윈도우 캡처는 투명 창의 알파를 살리지 못해 배경이 검게 잡힙니다.

단색으로 채운 뒤 방송 툴에서 색상 키를 거세요.

가능하다면 투명 모드 + 디스플레이 캡처 쪽이 외곽에 색 테두리가 남지 않아 더 깨끗합니다.

게임이 전체 화면(exclusive fullscreen) 모드면 윈도우 특성상 어떤 오버레이도 그 위에 표시되지 않습니다. 

테두리 없는 창 모드를 사용하세요.

## 한계

- 클릭 통과가 Win32 메시지(`WM_NCHITTEST`)에 의존하므로 윈도우 전용입니다.
- 배경과 피사체 사이에 외곽선이 없고 색까지 같으면 경계를 찾지 못합니다.
- **둘러싸인 배경도 제거**는 흰·검·회색 배경에서 피사체 고유색과 구분할 수 없으므로, 채도가 높은 단색 배경일 때만 실제로 적용됩니다.
- 선화·일러스트·스티커에 적합하며, 사진처럼 외곽선이 없는 이미지에는 잘 맞지 않습니다.
- 큰 이미지나 긴 GIF는 백그라운드에서 처리합니다. 처리 중에는 기존 이미지가 유지되며, 완료 후 새 이미지로 바뀝니다.
